# 脉络（Lumen）

> **本地优先的极简白板，把 AI 辅助学习的过程结构化为"问题树"。**
> 每个节点是一个你问过的问题，每条连线是一次思维的延伸，每片叶子是一次 GPT 导出的回答。

**当前状态**：M0 收尾 · 设计与技术栈已定稿（Tauri 2.x + React + TS）· 即将进入 M1

---

## 它解决什么问题

用 ChatGPT / Claude 做研究时，知识是**线性聊天流**，但思考是**树状分叉**的：

- 想复用前面某个回答，只能反复滚动找
- 导出成 Markdown 存文件夹后，信息变成一堆无结构的平铺文件
- "这个问题从哪个问题分叉出来的"完全丢失——只留下一地树叶，看不到树

脉络把这三者重新组织起来：**白板画布 + 问题树 + 本地 Markdown 库 + 离线公式阅读器 + 白板感知的 AI 助手**。

## 核心概念

```
项目 Project  一门学问 / 一个长期方向（如「扩散模型」）
 └─ 白板 Board   一个研究主题（如「数学基础」）
     └─ 节点 Node    一个你问过的问题（如「什么是 ELBO？」）
         └─ 文档 Doc     一次 GPT 导出的回答（.md，二期支持 .pdf）
```

- **节点**：圆角方框包裹问题标题；悬停看简介，点击看全文
- **连线**：有向 = 追问 / 派生，无向 = 相关
- **阅读窗口**：点击文档在**独立于白板**的窗口中打开，完整渲染 Markdown 与 LaTeX 公式（Android 应用 **mdread** 的桌面移植，作为本项目的子集功能）
- **AI 对话**：悬浮按钮展开，默认以当前白板为上下文，通过工具调用**按需读取**该白板的 Markdown 文件

## 数据存储

**文件即数据，不用数据库。** 你指定一个根目录，每块白板就是其中一个文件夹：

```
<你指定的目录>/
├── index.json
└── <项目>/
    ├── project.json
    └── <白板>/
        ├── board.json      # 节点、连线、树状结构
        └── docs/*.md       # 该白板的全部 Markdown 原文
```

好处：可用 Git 管理、可整体备份迁移、AI 直接读文件夹、软件卸载后数据仍在。

## 技术栈（计划）

| 环节 | 选型 |
| --- | --- |
| 外壳 | **Tauri 2.x**（Rust 后端 + 系统 WebView） |
| 前端 | React 18 + TypeScript + Vite + Zustand |
| 画布 | 自研：SVG 连线层 + DOM 节点层 |
| 渲染 | 复用 mdread 内核：markdown-it 定制规则 + KaTeX（全部离线内置） |
| 存储 | 文件系统 + JSON（原子写） |
| 测试 | Vitest + Playwright + mdread 回归套件 |

技术栈已定稿（Tauri 2.x）。平台策略见 [DESIGN.md §11 跨平台与发布策略](./docs/DESIGN.md#11-跨平台与发布策略)。

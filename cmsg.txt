fix(macos): use native window decorations to restore traffic-light buttons

Root cause of the missing red/yellow/green buttons: decorations:false
removes the native traffic lights AND rounded corners on macOS. The
v0.1.2 CSS corner hack worked around the corners but the buttons were
still gone.

Switch macOS to native decorations (decorations:true + titleBarStyle
Overlay + hiddenTitle), which brings back the traffic lights, native
rounded corners and window shadow in one shot. Windows keeps the
borderless custom titlebar buttons.

- add src-tauri/tauri.macos.conf.json (platform override for main window)
- aiWindow/windowManager: decorations/transparent = isMac (runtime
  platform check via api.appInfo); native decorations for AI & reader
  windows on macOS too
- styles.css: drop the platform-macos CSS corner/clip hack (native
  decorations handle corners now)
- bump version to 0.1.3

typecheck + vite build green.

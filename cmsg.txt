fix(macos): round window corners on main/AI/reader windows

macOS strips the system rounded corners from borderless windows
(decorations:false) — unlike Windows 11 which re-adds them automatically
(Tauri #12042). Result: sharp square corners on macOS only.

Fix (frontend self-draws corners + native material radius to match):
- settings.ts: add platform-macos class to <html>
- styles.css: on macOS, transparent shell + .board-surface radius 10px
  overflow:hidden (and AI/reader standalone roots); no radius in fullscreen
- lib.rs: native material corner radius 0 -> 10 (liquid-glass + vibrancy),
  expose apply_window_corners command for JS-created windows
- AiApp/ReaderApp: re-applySettings with platform, call apply_window_corners
- aiWindow/windowManager: transparent:true so corners can show through
- api.ts: applyWindowCorners binding
- bump version to 0.1.2

typecheck / cargo check / vite build all green.

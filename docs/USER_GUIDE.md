# 脉络 Lumen · 使用手册

> 本地优先的极简白板，把 AI 辅助学习的过程结构化为「问题树」。
> 每个**节点**是你问过的一个问题，每条**连线**是一次思维的延伸，每篇**文档**是一次 AI 回答的原文。

本手册面向使用者，覆盖首次启动、日常操作、快捷键、AI 助手、导出、快照与数据管理。开发相关请看 [README.md](../README.md) 与 [docs/DESIGN.md](./DESIGN.md)。

---

## 1. 首次启动引导

第一次打开脉络时，按下面四步就能建立你的第一块白板。

### ① 选择存储目录
应用不使用数据库——**你的所有数据就是一个文件夹**。首次启动会让你选择一个「存储根目录」（例如 `D:\Lumen` 或 `~/Documents/Lumen`）。

- 可以放在网盘 / Git 仓库里，实现同步与版本管理。
- 以后可在标题栏菜单「更改存储目录…」随时切换。
- 换电脑时把这个文件夹拷过去、重新指向它，全部项目原样恢复。

### ② 新建项目与白板
- **项目 Project** = 一门学问 / 一个长期方向（如「扩散模型」）。
- **白板 Board** = 项目下的一个研究主题（如「数学基础」）。

在左侧栏点 `＋` 或右键空白处即可新建。先建项目，再在项目下建白板。

### ③ 创建你的第一个节点
打开白板后，在画布上：

- **双击空白处**，或按 <kbd>N</kbd>（在视图中心新建），即可创建一个节点；
- 节点创建后自动进入编辑，输入问题标题（如「什么是 ELBO？」）回车确认；
- 单击节点在右侧打开**节点面板**，可编辑标题、简介、颜色标记、关联文档。

### ④ 连接节点，长出「问题树」
- 把鼠标移到节点边缘，从**锚点拖拽**到另一个节点即可建立连线；
- **有向连线**（带箭头）= 追问 / 派生；**无向连线** = 相关；
- 选中连线可加标签或删除。随时按工具栏「整理布局」自动排成树状。

> 提示：任何时候按 <kbd>?</kbd>（即 <kbd>Shift</kbd>+<kbd>/</kbd>）都能调出快捷键帮助。

## 2. 界面速览

| 区域 | 说明 |
| --- | --- |
| **标题栏菜单** | 设置、全屏、全局搜索、快捷键帮助、快照与恢复、导出、更改存储目录 |
| **左侧栏** | 项目列表 / 白板列表；右键新建、重命名、删除 |
| **画布** | 节点与连线的主工作区；可平移（拖拽空白）、缩放（滚轮 / 快捷键） |
| **画布工具栏** | 撤销、重做、整理布局、缩放（−/百分比/＋）、适配全部内容 |
| **节点面板** | 单击节点后在右侧停靠：标题、简介、颜色、关联文档（独立滚动） |
| **阅读窗口** | 点击文档在独立窗口打开，完整渲染 Markdown 与 LaTeX 公式 |
| **AI 悬浮按钮** | 右下角，展开独立的白板感知对话窗口 |

## 3. 快捷键

> macOS 用 <kbd>⌘</kbd>，Windows / Linux 用 <kbd>Ctrl</kbd>（下表统一记作 **Mod**）。
> 在输入框 / 文本域中打字时，画布级快捷键会自动让位，不会误删节点。

### 全局
| 操作 | 快捷键 |
| --- | --- |
| 全局搜索（跨全部白板） | **Mod + K** |
| 快捷键帮助 | **Shift + /**（即 **?**） |
| 进入 / 退出全屏 | **F11** |

### 视图
| 操作 | 快捷键 |
| --- | --- |
| 放大 | **Mod + =** |
| 缩小 | **Mod + -** |
| 缩放重置为 100% | **Mod + 0** |
| 适配全部内容到屏幕 | **Shift + 1** |

### 画布
| 操作 | 快捷键 |
| --- | --- |
| 在视图中心新建节点 | **N** |
| 撤销 | **Mod + Z** |
| 重做 | **Mod + Shift + Z** 或 **Mod + Y** |

### 节点
| 操作 | 快捷键 |
| --- | --- |
| 删除选中的节点 / 连线 | **Delete** 或 **Backspace** |
| 微移选中节点 | **方向键**（按住 **Shift** 步长更大） |
| 取消选中 / 关闭面板 | **Esc** |

> 此表与应用内「快捷键帮助」面板（<kbd>?</kbd>）同源，均由 `src/canvas/shortcuts.ts` 定义，不会漂移。

## 4. 文档与阅读窗口

- **导入文档**：在节点面板的「关联文档」区导入 `.md`（也支持 `.pdf`），文件会被复制进该白板的 `docs/` 目录，重名自动处理。
- **打开阅读**：点击文档条目在**独立窗口**打开，完整渲染标题层级、Markdown 与 LaTeX 公式，支持连续滚动 / 单页 / 双页（PDF 阅读器式）与全屏。
- **PDF**：点击 PDF 会调用系统默认程序打开。
- **公式**：行内 `$...$` 与块级 `$$...$$` 均离线渲染（KaTeX），目录中的公式也会渲染。

---

## 5. AI 助手

点右下角悬浮按钮展开独立 AI 对话窗口：

- **白板感知**：默认以当前白板为上下文，AI 通过工具**按需读取**白板大纲、节点列表与文档正文，而非一次性塞入全部内容。
- **配置**：在设置里填入 OpenAI 兼容服务的 `baseURL` 与 `API Key`（Key 经操作系统凭据库加密存储，不落明文）。
- **引用回链**：AI 回答里引用的节点会显示为可点击的**标题胶囊**，点击直接跳到白板并高亮该节点。
- **表格 / 加粗 / 公式**：正常渲染。
- **对话历史**：长期保存在该白板文件夹的 `chats.json` 中，退出不丢，可多会话切换。

---

## 6. 全局搜索

按 **Mod + K** 打开：跨**全部项目与白板**检索节点标题、简介、文档标题与正文。输入即搜，<kbd>↑</kbd><kbd>↓</kbd> 选择、<kbd>Enter</kbd> 打开，命中处高亮，点击结果直接跳到对应白板并高亮节点。

---

## 7. 导出

标题栏菜单 →「导出 · …」，导出当前白板：

| 格式 | 说明 |
| --- | --- |
| **Markdown（.md）** | 保留父子层级 + 简介 + 文档 + 关系一览，纯文本可再加工 |
| **HTML（.html）** | 独立内联样式，双击即可离线在浏览器打开 |
| **图片 SVG** | 矢量，按节点坐标绘制卡片 + 连线，随主题配色 |
| **图片 PNG** | 位图（2× 清晰度），适合贴进文档或分享 |

导出文件写入该白板的 `exports/` 目录。

---

## 8. 快照与恢复

标题栏菜单 →「快照与恢复…」：

- 每次**打开白板**会自动存一份快照（内容没变则跳过），**保留最近 20 份**。
- 也可随时点「存快照」手动保存。
- 点「恢复」回滚到某个历史版本——恢复前会**先把当前状态存成「恢复前保险」**，可再次回退，安全无损。
- 快照存在白板自己的 `.snapshots/` 目录，随文件夹整体迁移。

## 9. 数据存储与备份

**文件即数据，不用数据库。** 目录布局：

```
<你指定的存储目录>/
├── index.json                     # 项目索引
└── <项目>/
    ├── project.json
    └── <白板>/
        ├── board.json             # 节点、连线、树状结构、视口
        ├── docs/*.md              # 该白板的全部 Markdown 原文
        ├── chats.json             # AI 对话历史
        ├── exports/               # 导出产物（md/html/svg/png）
        └── .snapshots/            # 历史快照（最近 20 份）
```

- **备份 / 迁移**：直接拷贝整个存储目录即可。
- **版本管理**：把存储目录纳入 Git，可获得完整历史。
- **卸载无损**：软件卸载后数据仍在你的文件夹里。

## 10. 无障碍与个性化

- **三套主题**：在设置里切换，全局统一。
- **动效**：尊重系统「减弱动态效果」（`prefers-reduced-motion`）——开启后动画自动降级。
- **键盘可达**：主要操作均可用键盘完成；对话框与工具栏带 ARIA 标签。
- **缩放**：界面在系统缩放 / 高 DPI 下不破版。

# 项目画布

Lumen 打开后显示项目首页。首页可新建和摆放项目。单击文件夹会在画布上展开它的子项目和白板，同层的其他卡片一起让开空间。展开时可以看到里面已保存的箭头和名称。再次单击收起。展开时可切到同层的其他文件夹，也可以直接打开预览里的白板。

双击文件夹进入这一层，就可以新建或整理该层的子项目和白板。通过顶部路径返回时，恢复到该层展开前的摆放和视野。键盘可聚焦文件夹后按空格展开或收起，按回车进入。

- 拖动项目或白板卡片可以自由摆放。拖到另一个文件夹的图标上会将该项目移入对方；右键菜单里的「移到项目」也可以选择任意可用的上级或首页。
- 鼠标移到文件夹或白板卡片上，从右侧圆点拖到同层另一张卡片，就会保存从起点指向终点的箭头。文件夹与白板可以互连。右键菜单的「连到项目」和「连到白板」也可建立连线。连线默认是直线。拖动线条可以弯折，拖回两张卡片之间可吸附为直线。单击箭头或其名称即可编辑，回车保存，按 Esc 取消。名称支持 Markdown 和公式，例如 `应用到这篇论文 $\nu^2$`。右键箭头可拉直或删除连线。
- 打开不同层级时，顶部路径会列出经过的项目。点任一级可返回，左侧标志可直接回到首页。左下角的百分比可适配这一层的全部卡片。
- 右上角保留设置和菜单，知识库和导入、导出等入口在菜单里。

## 项目和白板封面

右键项目文件夹或白板卡片，选择「更换封面」。可以从 38 张图片和 6 款简约样式中挑选，点击「应用封面」后在卡片上看到效果。文件夹的图片会沿整个轮廓裁切，并连续铺到左上角的页签。正面的半透明高光和页签上的阴影保留了文件夹的前后层次。选「默认封面」可恢复原来的图标。图库可以离线使用。

封面跟随卡片保存，移动项目或重开应用后仍会显示。项目和全库资料包含封面选择。含封面的资料包可用 Lumen 0.2.2 或更新版本恢复。

## 标签与筛选

右键文件夹、白板卡片或节点，选择「编辑标签」。节点面板也有这个入口。每项可以同时拥有多个系统颜色标签和自定义标签。新建标签时选颜色并填写名称，保存后它可以用于同库的其他内容。已有的节点颜色标记直接参与筛选。

点右上角的眼睛选择标签，匹配其中任一个的内容会显示。每层独立记住当次筛选，点「全部内容」可恢复完整视图。白板连线随可见端点显示，子流程里有匹配步骤时会保留流程入口和步骤的原编号。

项目层级、卡片坐标、箭头名称和标签自动保存在桌面资料库。连线两端移到不同层时，关系仍保留，重新处在同一层时会显示。每层视野单独保存在本机窗口偏好。

## 备份与恢复

要迁移整套项目结构，通过右上角菜单「导出 → 备份全部内容」。只迁移一棵项目树时，在该项目卡片的右键菜单里选择「导出完整项目资料包」。两种资料包都保留包内的项目层级、卡片位置、收藏、封面、标签、连线、白板设置、子流程和文档原件。

用「导入 → 项目/全库资料包（恢复到新目录）」选择包和恢复位置。Lumen 校验资料后新建一个独立资料库，再询问是否打开。项目包以导出的项目作为新库的入口。含白板卡片连线的包可用 Lumen 0.4.0 或更新版本恢复。保存了卡片连线弯折的资料包需要 0.4.1 或更新版本。

「白板资料包」用于将一块白板作为新副本放入当前项目。跨端 WebDAV 同步白板内容，桌面项目画布通过项目或全库资料包转移。

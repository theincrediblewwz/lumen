# 项目画布

Lumen 打开后显示项目首页。首页可新建和摆放项目。点开项目后，可以在该层新建子项目或白板，再继续进入更深层。

- 拖动项目或白板卡片可以自由摆放。拖到另一个文件夹的图标上会将该项目移入对方；右键菜单里的「移到项目」也可以选择任意可用的上级或首页。
- 鼠标移到文件夹上，从右侧圆点拖到同层另一个文件夹，就会保存从起点指向终点的箭头。「连到项目」提供键盘入口。点击或右键点击箭头可删除该连线。
- 打开不同层级时，顶部路径会列出经过的项目。点任一级可返回，左侧标志可直接回到首页。左下角的百分比可适配这一层的全部卡片。
- 右上角保留设置和菜单，知识库和导入、导出等入口在菜单里。

项目层级、卡片坐标和项目箭头自动保存在桌面资料库。两端移到不同层时，路径仍保留，重新处在同一层时会显示。每层视野单独保存在本机窗口偏好。

原有项目会出现在首页，白板和原件继续使用现有路径。全库资料包会备份项目画布。项目资料包会包含该项目下的所有子项目，并保留包内端点完整的连线。跨端 WebDAV 继续同步白板内容，项目画布的层级、坐标和箭头通过桌面资料包转移。

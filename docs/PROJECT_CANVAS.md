# 项目画布

Lumen 打开后显示项目首页。首页可新建和摆放项目。点开项目后，可以在该层新建子项目或白板，再继续进入更深层。

- 拖动项目或白板卡片可以自由摆放。拖到另一个文件夹的图标上会将该项目移入对方；右键菜单里的「移到项目」也可以选择任意可用的上级或首页。
- 鼠标移到文件夹上，从右侧圆点拖到同层另一个文件夹，就会保存从起点指向终点的箭头。「连到项目」提供键盘入口。单击箭头或其名称即可编辑，回车保存，按 Esc 取消。支持 Markdown 和公式，例如 `应用到这篇论文 $\nu^2$`。右键箭头可删除连线。
- 打开不同层级时，顶部路径会列出经过的项目。点任一级可返回，左侧标志可直接回到首页。左下角的百分比可适配这一层的全部卡片。
- 右上角保留设置和菜单，知识库和导入、导出等入口在菜单里。

## 项目和白板封面

右键项目文件夹或白板卡片，选择「更换封面」。从 38 张内置封面中挑选一张，点击「应用封面」即可在卡片上看到效果。选择「默认封面」可恢复原来的文件夹或白板图标。图库可以离线使用。

封面跟随卡片保存，移动项目或重开应用后仍会显示。项目和全库资料包含封面选择。含封面的资料包可用 Lumen 0.2.2 或更新版本恢复。

## 标签与筛选

右键文件夹、白板卡片或节点，选择「编辑标签」。节点面板也有这个入口。每项可以同时拥有多个系统颜色标签和自定义标签。新建标签时选颜色并填写名称，保存后它可以用于同库的其他内容。已有的节点颜色标记直接参与筛选。

点右上角的眼睛选择标签，匹配其中任一个的内容会显示。每层独立记住当次筛选，点「全部内容」可恢复完整视图。白板连线随可见端点显示，子流程里有匹配步骤时会保留流程入口和步骤的原编号。

项目层级、卡片坐标、箭头名称和标签自动保存在桌面资料库。连线两端移到不同层时，关系仍保留，重新处在同一层时会显示。每层视野单独保存在本机窗口偏好。

原有项目会出现在首页，白板和原件继续使用现有路径。全库资料包会备份项目画布及标签。项目资料包会包含该项目下的所有子项目，并保留包内连线与相关标签。跨端 WebDAV 同步白板内容，项目画布与标签通过桌面项目或全库资料包转移。

# 素材分页与子白板

有完整问题和附件的节点会先显示标题、完整问题和第一份附件的预览。完整问题与附件分别翻页。

在节点面板的标题或 Markdown 编辑器中选中文字，松开鼠标后可点「高亮」。旁边的色块可切换荧光色或自选颜色。下次高亮时会记住最近一次选择。画布和文档预览用黑色文字显示这段内容，高亮随原文自动保存。

预览底部的单箭头在同一份素材内翻页，双箭头跳到上一份素材的末页或下一份素材的首页。第一份素材的首页收起左箭头，最后一份素材的末页收起右箭头。底部中间用描边数字标出素材序号，右侧用「当前页/总页数」标出这份素材的阅读进度。按钮聚焦后也可用左右方向键或 Page Up/Page Down。PDF 按原始页面预览，图文包中的本地图片和公式照常渲染。

下一张图片会按自身分辨率和原比例调整显示大小，高分辨率图片不会沿用上一张小图的尺寸。可用“适配全部内容”或画布缩放查看全图。阅读位置保存在当前窗口的有限内存中，移出视野再返回或收起子板预览后可继续；这类浏览操作不修改文档、附件顺序或节点数据。

子白板右边缘可拖动加宽，也可聚焦边界后用左右方向键调节。顶栏的“收起预览”只保留子流程步骤标题和编号，便于查看长流程；“展开预览”恢复素材和阅读位置。此开关只影响当前子白板，不改变母白板。

含有子流程的节点带有同色系的明亮呼吸光边，缩成热力区域后仍会保留标记。系统启用减少动态效果时，使用静态亮边。子白板四角的光路位于内容面板下方，并会避开右侧面板的位置。

应用图标改为明亮绿色，保留白色分叉节点图形。上述预览与显示改进不需要迁移原有资料；编辑和白板设置继续沿用自动保存。

## 专注视图

选中白板节点，点击右上角的「专注视图」。画布只显示这个起点和沿有向箭头到达的下级节点。起点挂载的流程按顺序展现，步骤旁有青蓝色荧光标记，大图按分辨率等比扩大。下级节点自己的流程保持收起。

滚轮缩放，拖动空白平移，双击卡片可居中阅读。左上角可回到起点、适配整个分支，或定位到已展开的流程。点「退出专注」或按 Esc 即可回到原白板的布局、缩放和阅读进度。

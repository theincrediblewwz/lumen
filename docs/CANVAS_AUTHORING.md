# 白板编辑与保存（0.1.15）

## 0.1.17 图片边框与阴影

[下载Mac0.1.17](https://github.com/theincrediblewwz/lumen/releases/tag/mac-v0.1.17)。图文节点的图片与标准框体对齐，不再向外越界或重复留下底部空白；图文沿用普通节点边框和阴影，纯图片阴影略深。图片比例、四角缩放、框外连线和悬停控件保持。三主题/1440和720px真实App及独立原生验证通过，无数据迁移。以下0.1.15/0.1.16的编辑、保存与备份能力继续保留。

[下载Mac0.1.15预发行](https://github.com/theincrediblewwz/lumen/releases/tag/mac-v0.1.15)。桌面、Rust、Android CI及完整Mac203组界面/双架构/签名/原生启动检查均通过，5份附件摘要已核验。

项目和白板旁的星标用于收藏置顶，收藏按当前资料目录保存在本机。白板设置位于“问 AI”旁，可选择字体与12–32px字号，逐板保存。

在节点面板点击唯一的“Markdown 编辑器”入口，打开专用窗口。第一行选择完整问题或关联文档，也可新建Markdown；右侧显示保存状态、立即保存与关闭。第二行提供常用格式、编辑/分栏/预览。标题和正文支持Markdown及公式，裸命令如`\nu`也可渲染。面板只保留标题输入和正文预览。

白板内容即时更新，停止修改约600ms后自动保存；文档编辑约650ms后自动保存。点击画布、切换文档、保存并关闭、窗口关闭和Cmd+Q都会等待当前写入。Cmd/Ctrl+S或“立即保存”可主动保存，无须每次手动保存。失败状态保留编辑并允许重试，未保存成功不会静默关闭编辑器。

完整问题与图数据在同一可恢复事务中保存为`docs/question_<nodeId>.md`。只浏览旧白板不会批量创建问题文件。普通Markdown编辑比较打开时的正文，发现其他窗口修改时拒绝覆盖并保留草稿；原版本和最多19份近期编辑历史保存在白板目录的`.document-history`。外部改过的问题Markdown也不会被静默覆盖。

右键空白画布“插入贴图”，也可粘贴图片或拖入PNG/JPEG/GIF/WebP，单张最多16MiB。画布只显示原比例图片，没有卡片底色、边框、数字和常驻图标；悬停才出现名称/控件，单击打开面板。贴图四角保持比例缩放，文字节点四角可独立调整宽高。原图片随资料包保留。

连线在目标节点外26屏幕像素范围松开即可吸附。左上只有撤销、重做、整理和适配全部；左下仅显示透明百分比，可点击恢复100%。最低缩放0.1%，低于35%开始按空间逐级聚合为热力区域，越小合并越多，放大后恢复细节。万节点/9999边验收在全局适配时只挂载45个热力区域。

升级前可用顶栏导出完整资料包。Mac安装版本为0.1.15，ad-hoc签名、未公证；已有资料目录和连接配置保持。旧版本及发行附件保留，遇到问题可退出后恢复旧App；更早App可能不会显示新贴图和字体设置，恢复前保留最新资料副本。Android本轮未重发安装包。

长分享还会等待虚拟消息区域完成刷新后才继续滚动，避免页面位置先更新导致跳过一屏；原600条及延迟刷新120条逐条保全。读取超时会明确停止，原文未截断。

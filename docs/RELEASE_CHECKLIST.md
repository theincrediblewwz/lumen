# 发布前实机验收清单（v0.1.0）

> 配套 [ACCEPTANCE.md](./ACCEPTANCE.md)（全量映射）与 [PERF.md](./PERF.md)（性能目标）。
> 本文件只收 **必须在真实构建产物上人工走查** 的项（ACCEPTANCE 里标 ⏳ 的条目 + 本期新功能）。
> 用法：按组照着操作，逐条打勾并把实测值填进「实测记录」。全绿即 M7-4 / M7-5 可收口。

**被测产物**：Release `v0.1.0`（<https://github.com/theincrediblewwz/lumen/releases>）
- Windows：`Lumen_0.1.0_x64-setup.exe`（NSIS，4.04MB）或 `Lumen_0.1.0_x64_en-US.msi`（5.34MB）
- macOS arm64：`Lumen_0.1.0_aarch64.dmg`（5.38MB）

**签名说明（一期 ad-hoc 未签名）**
- macOS 首次打开若报「已损坏/无法验证开发者」→ 右键图标「打开」→ 确认；或 `xattr -dr com.apple.quarantine /Applications/Lumen.app`。
- Windows 若弹 SmartScreen「Windows 已保护你的电脑」→ 「更多信息」→「仍要运行」。

## C. 输入手感与中文 IME（FR-3 验收）

- [ ] **C1 新建响应 ≤150ms**：右键空白→新建节点→立即可输入标题，无明显延迟。**实测记录**：______ ms（体感/录屏）
- [ ] **C2 中文 IME 提交**：双击节点标题，用拼音输入法打一段中文，**候选词上屏正常**，Enter 提交不吞字、不重复、不把拼音串写进标题。
  - 额外：输入过程中按 Enter 选词 **不应误触发"提交并退出编辑"**。**实测记录**：______
- [ ] **C3 IME 在阅读窗/AI 输入框**：同样方式在 AI 对话输入框打中文，正常。

## D. 文档导入与缺失（FR-5 验收 + 新功能）

- [ ] **D1 多选导入落盘**：节点面板「导入文档」一次选 3 个 .md → 3 个都挂到该节点，且实际文件复制进 `<白板>/docs/`（去资源管理器确认）。**实测记录**：______
- [ ] **D2 重名加后缀**：导入两个同名 `a.md` → docs/ 里第二个自动加后缀，不覆盖。
- [ ] **D3【新功能】拖 .md 到节点**：从桌面/资源管理器拖一个 `.md` 文件到白板上**某个节点**上方，松手。
  - 拖动时目标节点**高亮**（虚线描边）+ 底部出现「松开鼠标，把文档嵌入该节点」。
  - 松手后显示「正在导入文档…」，完成后该节点被选中并短暂闪烁，面板里出现该文档，文件进 `docs/`。**实测记录**：______
- [ ] **D4【新功能】落点精度（高分屏/缩放）**：在 **150%/200% 屏幕缩放** 或画布放大/缩小后，重复 D3，确认挂到的是**光标正下方那个节点**，不会错挂到相邻节点。**实测记录**：______
- [ ] **D5【新功能】拖到空白处**：把 .md 拖到没有节点的空白区域松手 → 只提示不导入，不建节点、不报错。
- [ ] **D6【新功能】拖非 md 文件**：拖一个 `.txt`/`.pdf`/图片到节点 → 弹「只能拖入 Markdown 文件」，不导入。
- [ ] **D7 外部删文件不崩**：在资源管理器里删掉某节点已挂的 md → 回到应用打开该文档 → 显示「缺失/无法读取」之类提示，应用不崩溃。**实测记录**：______

## E. 阅读窗（FR-6 验收）

- [ ] **E1 大文档首屏 < 500ms**：准备一个约 400KB、含数百个公式的 .md，从节点点击打开阅读窗，计首屏渲染时间。
  - 目标：< 500ms（PERF）。**实测记录**：______ ms
- [ ] **E2 滚动不掉帧**：在该大文档中快速滚动到底，主观流畅、无明显卡顿。**实测记录**：______
- [ ] **E3 目录跳转**：TOC 点击跳转并高亮对应标题；TOC 里的公式也正常渲染。
- [ ] **E4 多开互不影响**：同时开 2~3 个阅读窗，白板照常操作。
- [ ] **E5 编码回退**：打开一个 GB18030/带 BOM 的中文 md，正常显示不乱码。
- [ ] **E6 单页/双页 + 字号 + 主题**：切单页/双页均连续滚动；A−/A+ 生效（双页放大重排不溢出）；三主题与白板联动。

## G. AI 对话（FR-7 验收，需有效 API Key）

- [ ] **G1 配置供应商**：设置里填 OpenAI 兼容 baseURL + Key，保存后 Key 不明文显示。
- [ ] **G2 引用真实节点**：在一块 ≥20 节点、有实际内容的白板上提问 → 回答**引用 ≥3 个真实节点**（显示节点标题而非 `[[node:xx]]` id），**点击引用跳转并高亮**对应节点。**实测记录**：______
- [ ] **G3 表格/加粗/公式渲染**：让 AI 输出一个含表格、加粗、行内/块级公式的回答 → 表格真正渲染成表、加粗正常、公式 KaTeX 渲染，无 `∗∗`/`∣--∣` 乱码。
- [ ] **G4 流式可中断/可重试**：长回答生成中点「停止」能立即中断；失败后可重试。
- [ ] **G5 拔网优雅报错**：断网后提问 → 友好错误提示，应用不崩溃、可恢复。**实测记录**：______
- [ ] **G6 对话持久化**：关掉 AI 窗甚至退出应用后重开 → 该白板的历史对话仍在（存于 `<白板>/chats.json`）。

## H. 快捷键与可访问性（抽查）

- [ ] **H1 帮助面板**：按 `?`（Shift+/）弹出快捷键帮助，内容与实际一致。
- [ ] **H2 核心快捷键**：Mod+K 搜索、Mod+Z/Mod+Shift+Z 撤销重做、Mod+± / Mod+0 缩放、Shift+1 适应、N 新建、方向键微移、Delete 删除、Esc 取消。

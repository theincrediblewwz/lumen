# AI 工作区

在项目首页或项目内点击右下角「AI 工作区」。打开白板后，可以从右上角菜单进入。模型使用应用已有的 AI 连接，工作区也提供模型设置。

可以先试这样一句话。

> 在「数理研究」下面新建「方程讲义」项目，放一块「求解路径」白板。主节点写线性方程，连接「列式」「求解」「检验」三个分支。在「检验」里用子流程记录步骤，给关键节点加绿色标签，把白板收藏置顶。

模型先查找目标，生成一批待确认的操作。方案里可以展开看正文、标签和步骤顺序。点击「应用方案」后可以从回执打开新建的项目或白板。「撤销上一批」会恢复本地资料库里该批次的原始内容。打开、平移和缩放白板后仍可撤销。后续内容编辑会触发版本冲突，撤销会停下并保留编辑。工作区保留最近 12 批本机撤销记录。

## 原先的 AI 接口

| 工具 | 范围 |
| --- | --- |
| `read_board_outline`、`list_nodes` | 分页查看当前白板的节点与连线 |
| `read_node_doc`、`search_board` | 分段读当前白板的挂载文档，或按关键词检索 |
| `read_conversation`、`search_conversation` | 读取当前对话及检索历史消息 |
| `apply_board_operations` | 开启本机授权后，在当前白板创建节点、追加 Markdown、建立连线 |

旧写入接口采用 `lumen.board-operations/v1`。它支持三种操作 `create_node`、`append_document`、`connect_nodes`。已有正文编辑、删除、项目目录和白板创建在当时属于人工操作。另有对话导入、模型目录检查等专门入口。

## 新的 AI 接口

模型使用 `inspect_workspace` 查目录、项目箭头、白板、标签和内置封面。勾选「允许读取现有白板的节点、连线和附件正文」后，它还可以查看节点、完整问题、子流程顺序、附件目录及 Markdown 片段。内容通过现有模型连接发送，分页结果带 `nextOffset`。本轮读取的资料会在生成方案时校验版本。

写入工具 `propose_workspace_changes` 使用 `lumen.workspace-operations/v1`，一批最多包含 160 项。新对象用 `@名称` 作批内引用，正式标识由程序生成。用户确认后，原生端再次校验资料库和文件版本，将所有文件放在同一事务内提交。

| 对象 | 可提出的操作 |
| --- | --- |
| 项目 | 创建、命名、移动到上级项目或首页、摆放、移除、编辑同层项目间的箭头名称 |
| 白板 | 在项目内创建、命名、摆放、移除，设置标题与预览字体、字号和缩放灵敏度 |
| 项目和白板卡片 | 设置或恢复内置封面、收藏置顶 |
| 节点 | 创建、编辑标题与完整问题 Markdown，设置颜色、位置、尺寸，移除节点 |
| 连线 | 创建、移除，设置有向或无向、公式名称、自动布线、直线、弯折和弯折点 |
| 子流程 | 创建、插入、调序及移除步骤，按顺序生成箭头，步骤可以挂载资料与打标签 |
| 文档和图片 | 新建或编辑 Markdown、重命名、调整挂载顺序，复用已入库的 Markdown、贴图、PDF 与导出包附件 |
| 标签 | 添加或取消系统颜色标签，创建、编辑、移除自定义标签，给项目、白板和节点分配标签 |

移除操作解除在目录或图谱中的引用，物理原文件保留。已有 Markdown 的改写会记录原始字节，撤销时可逐字节恢复。

文件选择、外部会话链接解析、备份导出、知识库和同步账号仍在各自的入口。AI 工作区里的对话保留到本次应用退出，应用后的撤销记录保留在资料库。本机文件和图片可以先导入白板，再由 AI 工作区查阅或挂载到新节点。

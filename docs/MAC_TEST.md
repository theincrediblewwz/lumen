# Lumen Mac 界面与 AI 配置测试包

1. 下载 `Lumen-Mac-提交号-universal.zip`，在 Mac 解压得到 **Lumen.app**，退出原 Lumen 后替换“应用程序”中的旧版。通用包包含 Apple Silicon 与 Intel 两种架构。
2. 包已作 ad-hoc 自签名，未做 Apple 公证。首次打开如被系统拦截，按 [Apple 官方说明](https://support.apple.com/zh-cn/102445) 在“系统设置 → 隐私与安全性”选择“仍要打开”。
3. 本包沿用原 Lumen 的应用身份与保存位置。知识库和白板、文档在同一资料目录，知识存于 `knowledge/library.json`；测试前保留原资料目录的副本。

建议重点测试：

- **0.1.13 项目和全部内容备份**：顶栏菜单“导出 → 导出当前项目…”打包该项目全部白板及关联知识/历史；“导出 → 备份全部内容…”打包当前资料库全部项目、独立知识、文档原件、对话、阅读记录和历史。项目右键也可导出。两类包均可从“导入 → 项目/全库资料包（恢复到新目录）…”恢复；请选择原库外的父目录，会生成新资料目录并核验文件，再询问是否打开。取消打开仍保留新副本与原库。连接、Key、本机AI授权、同步连接及临时任务不随包迁移。未保存草稿先保存；打包不包含尚未产生的回答。
- **0.1.13 长分享与逐轮选择**：读取公开分享后显示消息/轮次数，按第n轮分开；每轮可展开、折叠和勾选，全选/清空及只按需显示列表。默认全选，只有勾选内容发送给已连接模型；改变勾选使旧方案失效，需重新分析。写入后“原始对话”仍含全文，另有“本次整理的轮次”记录。结构化ChatGPT正文走完整当前分支；网页回退会定位开头、滚动内层容器并累计虚拟列表。文字预算32MiB、网页数据64MiB，没有500条限制；超预算/停滞明确报错，不静默截断。图片/附件仍需原件方式导入，模型内部思考/工具日志不当公开回答。
- **0.1.12 知识库第1版设计**：知识库独占工作区，左侧索引、右侧正文；标题栏三横线只收起知识索引，返回白板后恢复原项目/白板侧栏。顶部“写下理解”创建内容；支持标题/正文/出处搜索与三类筛选。条目旁明确目标白板，关联不自动开启AI引用；空结果、旧版本和缺失版本时，仍可从“更多”调整白板级权限。公式、不可变旧版本、出处/依据、归档恢复和AI草稿明确采用保留。导入导出及失败保稿与原数据格式兼容，没有迁移资料或Key。
- **0.1.11 操作与界面修复**：项目/白板右键“重命名”应出现原位输入框，Enter保存、Escape取消，中文输入法确认不误提交，失败保留名称草稿；重开后名称保留。新建或删除当前项目不残留旧画布。删除使用应用内确认，确认框内Delete、Backspace、方向键等不能改动底层画布，Enter可取消。
- **0.1.11 菜单与知识保护**：顶栏“导入”“导出”“视图与帮助”点击展开；设置中仍可更改资料目录。侧栏不应浮起或与顶栏留缝，通知不挤压界面。知识未保存时，从顶栏导入应先询问放弃，取消后草稿仍在。节点级知识引用及深层依据链已修复；知识库整体界面仍待用户选定候选图，不冒充已重做。
- **0.1.10 PDF兼容修复**：修正部分Mac在导入PDF或加载文字层时出现 `undefined is not a function`。新版不依赖流的异步迭代接口；若系统仍无法提取文字，会保存原件并明确说明，仍可阅读/导出，不将其冒充可检索正文。请重新导入0.1.9曾失败的文件并检查分页、选字。
- **0.1.10 图文资料**：将 GPT 导出工具生成的 PDF 或 Markdown 图片 ZIP 直接拖到节点，或在节点面板“＋ 导入”选择文件。ZIP 中的 `answer.md`、引用式图片和 HTML 表格图片应离线显示，公式沿用原阅读器排版。PDF 可翻页、输入页码、缩放、选中文字，并导出原 PDF；没有文本层时保留原件并明确说明 AI 读不到图片，不自动 OCR。
- 图文 Markdown 的下载图标导出“当前正文＋图片”的 ZIP；PDF 下载图标导出逐字节原件。顶栏菜单“导出 → 完整白板资料包（含原件）”用于迁移整板，另一安装从“导入 → 白板资料包…”恢复为新副本；正文、挂载、对话、知识引用和原始附件一并保留。普通 Markdown/HTML 图谱导出仍只是白板概览，不承担原件备份。
- 附件原件与图片随原存储目录保存；解除挂载只移除关联，撤销可重新挂回。白板历史包含挂载文档依赖的原件与图片。导入解析可停止，真正提交时暂时锁定编辑，完成后即解除；失败不得留下半个节点或半份附件。
- 单原件/图片包解压内容不超过 32 MiB，现有整库 WebDAV 单次处理预算仍为 64 MiB；超限会解释原因并保留本地资料。旧版 macOS 的 PDF 引擎可能不兼容，界面提供系统阅读器与原件导出。PDF 内嵌渲染以本次 Mac WebKit 及你的 Mac 实测为准。
- 0.1.10补齐Android新挂载PDF/图文ZIP的哈希路径别名投影，强化页数/提取状态校验；Android实际导出包已通过桌面原生往返。同次发行提供Android2.1.0-preview.8，阅读、文字引用、完整白板包和含原件备份恢复已在隔离模拟器验证；物理手机与真实WebDAV仍需分别测试。

- 历史对话列表右键（Mac也可Ctrl+点击）→“删除历史对话”，确认后只移除该会话；已保存的节点文档与知识保留。上方“撤销删除”可恢复，运行/待保存或有草稿的会话先处理完再删。删除原文后，已有笔记仍可读，返回原对话会说明已归档。
- 左键节点打开详情；右键只显示菜单。选择“移动本节点及全部下级”后拖动该节点，箭头指向的递归下级会同位移，其他独立树保持不动。整个移动只需一次撤销/重做；Esc取消，下次普通拖动仍只移动单个节点。
- 对话导入不设固定层数或节点数上限，默认“自动 · 按内容展开”；6/12/20/32是规划偏好而非限制。预览深层处标注真实层数，文件字节与模型实际额度保护仍生效。默认快速分析，也可开启“深入分析”；输出沿用你保存的上限，不再按节点数量压低。思考与正文进度分开，额度耗尽/空答/断流会明确提示并保留原文，不自动重试。
- 分享读取显示阶段与耗时，不再因图片等非正文资源一直等待；读到问答后会核对连续稳定和页面忙状态。遇登录/验证码/页面变化仍可停止后改用Markdown，前一次的迟到结果不会覆盖新输入。
- “深入分析”横向显示。对话操作按导出文件、新建节点、加入已有节点分组，选择框与对应按钮保持一起。整理布局为同层关系线及标签留出通道，增加独立树间距；适配全部也包含标签，一次撤销可恢复位置，节点/文档/关系文字不改动。
- 本次三轮审查：长输入框会自动增高，最高约屏幕三分之一后内部滚动，删短/发送后缩回；Shift+Enter 换行，输入法确认不误发送。有草稿时关闭 AI 窗改为隐藏，重开继续编辑。
- 同一会话若已在另一窗口生成，发送会保留当前输入并拒绝重复启动；另一窗口完成后重新打开该会话再发。聊天被同步修改时也会提示重载，避免问答错配。不同会话仍可在后台同时继续。
- 展开“对话操作”可“导出当前对话 Markdown”；自动保存失败时也有独立导出按钮和重试入口。导出请选择资料目录外的位置，避免覆盖原件。中文/长路径文档分别打开；重复打开或外部更新后阅读窗会刷新。

- 本次新增：节点面板“与 AI 对话”显示节点归属，分享开启时会读取该节点文档；保存问答默认接为下一层。历史按节点分开，多窗口会话分别合并保存。
- 选一条问题或回答，“保存为节点”均包含完整一轮。展开“对话操作”可选择已有节点并“存为节点文档”；每次追加新文档，原件保留，重复相同问答会打开原来的那篇。阅读器和节点预览的下载图标可导出原始 Markdown，公式支持 $…$、$$…$$、\\(…\\)、\\[…\\]。
- 设置或AI设置 → “AI 整理白板”，默认关闭。阅读知情说明并开启后，模型可使用工具创建节点、追加文档、连线，无须逐批确认；可随时关闭。开启读取白板也是前提，现有 Key/连接不变。操作JSON不显示为正文；每批最多8节点、8文档、12连线，每次发送最多4批。
- 每批修改前备份结构与关联原件到白板 `.ai-backups/`；每白板默认20份，可设1–100。白板菜单 → “快照与恢复…” → “AI 整理与文档版本”恢复；恢复前另存当前版本，聊天不回退。下方旧快照仅包含结构。网络中断/停止不会自动撤销已经成功的批次，可在此恢复。

- 打开项目和白板后，再点当前项目或项目栏空白处，白板列表收起但画布保留。单击画布空白收起两层侧栏，标题栏可重新展开；拖动画布、节点和双击新建不误收起。
- 右下角“问 AI”是轻量入口，新对话窗默认横向。正文行宽、输入框、右上角图标在浅色/纸感/深色下保持一致，Mac 原生交通灯正常。
- AI 设置中保存一套命名配置，再“另存为新配置”；切换并保存、重开软件后两套仍在，密钥分别保管。更换供应商或地址需重新填写密钥；取消不切换生效配置。
- 选择 DeepSeek、OpenAI、小米 MiMo、Qwen、Kimi、GLM、OpenCode Go/Console 或 OpenRouter；可选模型、编辑地址和自定义型号。Go 面向编程代理流量，通用学习用途未获服务商保证，需核对订阅适用范围。
- 温度已从常用界面移除，思考强度按当前模型给出真实档位，如低/高/Max或关闭/开启。OpenAI 当前白板 Chat 工具仍有协议限制，不会假装支持高思考工具组合。
- “推荐参数”分别采用高输入预算与输出上限；DeepSeek/MiMo 窗口精确值为 1,048,576。输入与输出共用窗口，实际资料较长时会按剩余空间下调输出，不会永久预扣整段最大输出。手填仍有边界，白板/知识授权不改变。
- 展开“模型目录”→“AI 检查更新”，使用当前已保存的 AI 连接查公开官网资料。此操作使用模型额度，但不发送白板、知识库、聊天或个人连接信息。先查看原文依据和修改差异，再点“应用目录更新”；可回退上一版。更新和回退都不保存、替换或删除你的连接与 Key，也不套用新的推荐值到已有配置。新推理协议仍需软件支持，AI 不能修改程序代码。
- “测试连接”使用当前表单草稿发送一条固定短问题，可能产生少量模型费用，不保存草稿。结果分别提示接口连接、鉴权和模型响应，20 秒超时；短测试通过不代表已经验证百万输入或最大输出。开发验收未使用真实 Provider。
- 模型与限制为 2026-10-22 官方文档快照；输入预算由应用扣除输出和请求预留计算，不能与模型总窗口等同。真实账号可用型号、实际计费/分词和服务端限制以供应商为准。
- 首页与侧栏仍简洁，知识入口只占一行，项目和白板目录都可见。
- 知识页的“← 白板”和侧栏切换能返回；未保存的理解会先确认，取消后内容仍在。
- 浅色、纸感、深色主题下，知识页、设置、AI 对话和引用预览的字号、留白与控件一致。缩窄主窗口、展开侧栏后内容仍可读。
- 主窗口、独立 AI 和阅读窗口保留 Mac 原生交通灯、圆角与阴影，没有重复 Windows 窗口按钮。
- 写一条理解、保存并重开；引用到白板并设置“按需/优先”。提问时查看引用预览，先取消验证问题还在；真实 AI 发送按你自己的权限和服务配置操作。
- 在旧回答中打开引用版本，确认仍可回看当时的理解；原白板和文档保持可读。

包中的 `build-info.txt` 标明准确源码提交与 Actions 地址，`SHA256SUMS.txt` 可核对文件。源码压缩包与运行包对应同一提交。

自动检查覆盖 Mac WebKit 界面、前端/数据合约、Rust 测试、双架构与签名、原生启动。真实 Mac 手工交互、系统文件选择器、AI/WebDAV 服务和你现有资料仍需本机测试。
- AI 设置 → 连接 → **密钥保存**：新配置默认“本机免提示保存”，仍可选择“系统钥匙串 / 凭据库”。旧配置保持原方式；要改为免提示，选择后点击保存。首次迁出旧 Key 可能仍需一次系统授权，也可手动重填 Key 避免读取旧钥匙串；原钥匙串条目不删除。
- 打开/关闭 AI 对话、查看设置、切换配置时不读取 Key。发送、测试连接、AI 检查目录和显式保存时才读取；系统模式成功授权后，在本次应用运行期间跨 AI 窗口复用。取消授权应保留问题、设置草稿、原配置和 Key，可再次点击重试。
- 本机模式使用 AES-256-GCM 加密，设备密钥同机保存在应用配置目录 `credentials-local/`，Mac 目录 0700、文件 0600，不进入白板/知识同步或导出。它不会弹钥匙串密码框，但对同一账号下其他程序的防护弱于钥匙串；不要单独删除 device.key。需要退回旧版前，先在新版切回系统凭据库并保存。

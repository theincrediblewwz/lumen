# 子流程与内容组合（0.1.16）

Mac预发行正在验收；发布后以Release附件的版本、摘要和BUILD-INFO为准。

## 0.1.16：节点内部流程与资源

单击一个普通节点，在右侧的「子白板 · 线性流程」创建流程。带流程的节点有柔和的发光边缘；再次单击会同时展开左侧流程和右侧节点面板，四条柔光路径标出它们的关系。点击母板空白处可一起收起。

流程右上角「编辑」进入编辑模式。右下角悬浮「添加步骤」追加到末尾；右键某一步可在下方插入或移除。拖动步骤上下换位，原来的箭头会按新顺序接成一条链；撤销/重做覆盖一次完整的拖动。编号显示在步骤框内部右侧。只露出一部分的步骤也可直接点击选中；真正开始拖动后才会在边缘自动滚动。每一步都能像普通节点一样挂多篇 Markdown 和多张图片。删除母节点会把步骤保留到母板，不会删掉文档原件。

在画布空白处粘贴图片或文字，会创建节点。超过20个字符的文字以前10个字符作为标题，全文完整保存为挂载的 Markdown。在节点面板的非输入区粘贴，会挂到当前节点；在文字输入框或编辑器里粘贴文字，仍然是正常编辑。画布和流程空白区也可以直接拖入 Answer Export 的 ZIP、Markdown、PDF 或图片。Answer Export 的正文、图片和原始 ZIP 都会保留，图文可离线打开。

标题下面预览按顺序排列的第一个资源；在面板里悬停资源，可用「置于首位」更换。允许空标题，但节点必须有正文、资源或实际流程步骤。只有图片时按原比例显示干净的图片和柔和阴影，操作信息仍在悬停时显示；只有文档时预览正文的开头。右下角白板设置分别调整标题和文档预览的字体、字号，节点面板不再重复设置按钮。

标题、完整问题和连线说明都支持 Markdown 和公式。输入与粘贴后节点自动撑开，四角缩放不会把文字裁到框外；「整理布局」会等待真实内容、图片和公式完成排版后再计算全部节点大小，可撤销。挂载文档在画布显示开头，完整内容仍可通过阅读器或 Markdown 编辑器打开。少数资源无法读取时会保留原布局并提示恢复资源后重试。

选中连线后拖动中间的圆点可调整弯折；靠近直线松开会吸成直线，向外拉开会变成弯线。普通连线随节点位置选择合适边缘端点。关系说明过小时显示三个发光小点；热力概览会合并邻近的提示，放大后恢复文字。

内容继续自动保存；点击母板、切换和关闭时会等待写入，失败保留草稿。Cmd/Ctrl+S 可立即保存，无需每次按快捷键。

---

已有资料不会批量迁移。升级前保留旧App和资料副本；副本导入重映射流程标识，原始Markdown/图片/ZIP保留。更旧App可能不会按子流程显示新增字段，回退前先保留最新资料副本。
